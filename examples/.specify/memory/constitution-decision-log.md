# Constitution Decision Log

Historical record of constitution amendments and breaking API changes, in reverse chronological order. Kept out of `constitution.md` itself to keep the constitution lean — every pipeline phase (plan/tasks/test/implement) reads the full `constitution.md` on every run, so a growing inline log would add to every prompt without informing any decision.

Read this file when investigating why a rule exists, or when drafting a new amendment and wanting precedent for tone/format. It is not required reading for routine spec/plan/tasks/test/implement work.

New entries are appended here, in this same table, as part of the same change that amends `constitution.md` (see §17 there). The full before/after text and downstream actions for each amendment go in `constitution_update_checklist.md`; this table is the one-line summary.
