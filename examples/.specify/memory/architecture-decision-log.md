# Architecture Decision Log

Historical record of architectural decisions, in reverse chronological order. Kept out of `architecture.md` itself to keep the architecture document lean — the Plan Agent reads the full `architecture.md` before every `plan.md`, so a growing inline log would add to every plan prompt without informing the plan.

Read this file when investigating why a past architectural choice was made, or when drafting a new decision entry and wanting precedent for tone/format. The Plan Agent does not need to read it to write a routine `plan.md` — only when drafting a new entry because a feature introduces a new architectural decision.

New entries are appended here, in this same table, as part of the same plan-phase change that proposes a new architectural decision (see constitution §9).
